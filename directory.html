Tutorial

Where do I paste the code?

You need to add the snippet to the HTML of the exact URL you submitted (usually your homepage). Pick your platform below.

WordPress — easiest (no code needed)
  1. In your WordPress dashboard, go to Appearance → Theme File Editor.
  2. Click footer.php in the list on the right.
  3. Find the closing </body> tag near the bottom.
  4. Paste the snippet just before </body>.
  5. Click Update File, then load your homepage and click Verify my site.

No-code alternative: install the free "Insert Headers and Footers" plugin, paste the snippet in its Footer box, and save.

WordPress — with a page builder (Elementor, Divi, etc.)
  1. Edit your homepage with the builder.
  2. Add an HTML widget (Elementor) or Code module (Divi).
  3. Paste the snippet into that widget and publish the page.
  4. Open your live homepage and click Verify my site.

Tip: drag the widget near the bottom of the page (like a footer) so it's out of the way.

Wix
  1. In the Wix editor, click Site → Site Tools → Custom Code.
  2. Click + Add Custom Code.
  3. Paste the snippet in the code box.
  4. Choose Place code in: All pages (or Home) and click Apply.
  5. Publish the site, then click Verify my site.
Squarespace
  1. In the editor, go to Pages → Home → ⚙️ (gear) → Advanced.
  2. Scroll to Header/Footer Code Injection.
  3. Paste the snippet into the Footer box.
  4. Click Save, then load your live homepage and click Verify my site.
Blogger (Blogspot)
  1. In Blogger, go to Theme → Edit HTML.
  2. Press Ctrl+F and search for </body>.
  3. Paste the snippet just before that tag.
  4. Click Save, then click Verify my site.
Shopify
  1. Go to Online Store → Themes → ⋯ → Edit code.
  2. Open layout/theme.liquid.
  3. Find </body> and paste the snippet just before it.
  4. Click Save, then click Verify my site.
Plain HTML site (hand-coded, GitHub Pages, Netlify, etc.)
  1. Open your homepage file (usually index.html) in a code editor.
  2. Scroll to the very bottom and find </body>.
  3. Paste the snippet just before </body>.
  4. Save the file and upload/deploy it to your host.
  5. Load your live homepage and click Verify my site.
Weebly, Jimdo, Strikingly & other builders

Most drag-and-drop builders have a "Custom Code", "Embed Code" or "HTML" element. Add that element to your homepage, paste the snippet inside it, and publish.

If you can't find it, Google: "[builder name] add custom HTML to homepage" — every builder supports it somewhere.

💡Common gotchas: the code must be on the exact URL you submitted (e.g. yourdomain.com or yourdomain.com/). After pasting, hard-refresh your page (Ctrl+Shift+R) so it's live before verifying.

FAQ

Directory questions

Is the backlink free?

Yes. Listing is free and there's no paid placement. We keep it free to keep the directory genuinely useful — the same ethos as our audit tool.

How long does approval take?

There's no manual wait. Add the verification snippet to your site, click Verify my site, and once we detect it you're listed immediately — with a backlink.

Do I need to link back to AmzLoss?

Yes — that's the deal. The verification snippet you paste contains a link back to our directory, plus your unique code. We check the code is really on your site before we list you, so nobody gets a backlink without actually linking back.

What if the snippet isn't detected?

Make sure it's pasted into the HTML of the exact URL you submitted, saved and deployed — then click verify again. Some sites block automatic checks; in that case contact us at admin@amzloss.com and we'll verify manually.

Does listing guarantee my site ranks higher?

No — no single directory link guarantees rankings. A relevant link like this is one small, natural signal among many. Focus on good content first.
